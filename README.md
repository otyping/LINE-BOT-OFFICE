# ระบบแจ้งตารางทำงานผ่าน LINE + อนุมัติโดย HR

ระบบให้หัวหน้างานแจ้งว่าพนักงานคนไหนเข้างานวันไหน เวลาใด ผ่านฟอร์มในแอป LINE จากนั้นหัวหน้า HR กดอนุมัติ แล้วข้อมูลจะลงใน Google Sheets อัตโนมัติ

## ที่มาของโปรเจกต์

เดิมหัวหน้างาน 3 คนส่งข้อความในกลุ่มไลน์ว่าวันนี้ใครเข้างานกี่โมง แล้วต้องมีคนนำไปกรอกในไฟล์ `KB_ตารางทำงาน_9-69.xlsx` เอง ระบบนี้มาแทนการพิมพ์ข้อความอิสระ ด้วยฟอร์มแบบกดเลือก ข้อมูลจึงไม่ผิดพลาดจากการสะกดชื่อ และไม่ต้องใช้ AI ในการแยกข้อความ

ทางเลือกที่พิจารณาแล้วแต่ไม่ได้เลือก:

- **ให้บอทอ่านข้อความอิสระในกลุ่ม** แยกชื่อและเวลาได้ไม่แม่น ต้องบังคับรูปแบบข้อความหรือใช้ AI ช่วย
- **ปุ่ม Quick Reply / Flex อย่างเดียว** เลือกได้ทีละปุ่ม ติ๊กเลือกหลายคนพร้อมกันไม่ได้ จึงใช้ LIFF (หน้าฟอร์มที่เปิดในแอป LINE) แทน
- **LINE Notify** ปิดบริการไปแล้วตั้งแต่ปี 2025

## ขั้นตอนการใช้งาน

1. หัวหน้างานพิมพ์ **จำปี** (ชื่อบอท) ในกลุ่ม บอทแสดงเมนูปุ่มกดให้ทันที
2. กด **แจ้งวันทำงาน** จะเปิดฟอร์ม LIFF ให้เลือกวันที่ เลือกเวลา (มีกะสำเร็จรูปพร้อมแถบ 24 ชม. หรือพิมพ์เวลาอื่น) และติ๊กเลือกพนักงานได้หลายคน ถ้าวันเดียวกันมีหลายกะ กด "เพิ่มกะเวลาอื่น"
3. กด **ตรวจสอบ** แล้วกด **ส่งขออนุมัติ**
   - ในชีท `บันทึกเวร` จะมีแถวใหม่สถานะ `รออนุมัติ`
   - ในกลุ่มจะมีข้อความสรุปที่ส่งในนามหัวหน้า (ไม่นับโควตาของบอท)
   - หัวหน้า HR ได้รับการ์ดแจ้งเตือนในแชทส่วนตัวกับบอท
4. HR กด **ตรวจและอนุมัติ** จะเปิดหน้ารายการรออนุมัติ ในหน้านี้ HR ทำได้สามอย่าง
   - อนุมัติหลายคำขอพร้อมกัน
   - แก้เวลารายคนก่อนอนุมัติ
   - ไม่อนุมัติพร้อมใส่เหตุผล (ตารางยังเป็นค่าเดิม ไม่มีอะไรเปลี่ยน)
5. เมื่ออนุมัติ แถวนั้นเปลี่ยนเป็นสถานะ `อนุมัติ` และบอทแจ้งผลให้หัวหน้าที่ส่งทราบในแชทส่วนตัว

### วิธีเรียกบอท

- พิมพ์ **จำปี** เฉย ๆ (หรือ `แจ้งงาน`, `เมนู`, `jampee`) บอทส่งการ์ดเมนูพร้อมปุ่มกด
- สั่งต่อท้ายชื่อได้เลย เช่น `จำปี ตารางวันนี้`, `จำปี ตารางพรุ่งนี้`
- เรียกชื่อแล้วสั่งคำที่บอทไม่รู้จัก บอทจะส่งเมนูให้กดแทนการเงียบ
- ทุกคำตอบมี **ปุ่มลัดใต้ช่องพิมพ์** (quick reply) ครั้งต่อไปกดปุ่มได้เลย ไม่ต้องพิมพ์ชื่อบอทซ้ำ
- ในแชทส่วนตัวกับบอท พิมพ์อะไรก็ได้ บอทตอบเมนูเสมอ ส่วนในกลุ่มถ้าไม่ได้เรียกชื่อ บอทจะเงียบ
- คำสั่งอื่น: `myid` (ดู userId ของตัวเอง)

เปลี่ยนชื่อบอทได้ที่ `CFG.BOT_NAME` และเพิ่มคำเรียกอื่นที่ `CFG.BOT_ALIASES` ใน `Code.gs`

### อยากให้เป็นปุ่มค้างไว้ ไม่ต้องพิมพ์เลย (ริชเมนู)

ริชเมนูคือแถบปุ่มใต้ช่องพิมพ์ที่ค้างอยู่ตลอด ทำได้ใน manager.line.biz โดยไม่ต้องแก้โค้ด

1. ตั้งค่า → **ริชเมนู** → สร้างใหม่ → เลือกเทมเพลตแบ่งช่อง แล้วใช้ตัวช่วยออกแบบใส่ข้อความบนปุ่มได้เลย
2. ตั้งค่าการกระทำของแต่ละช่อง
   - ช่อง "แจ้งวันทำงาน" → ประเภท **ลิงก์** → ใส่ `https://liff.line.me/<LIFF_ID>`
   - ช่อง "รออนุมัติ (HR)" → ลิงก์ `https://liff.line.me/<LIFF_ID>?page=approve`
   - ช่อง "ตารางวันนี้" → ประเภท **ข้อความ** → `จำปี ตารางวันนี้`
3. ตั้งช่วงเวลาแสดงผลเป็นไม่มีวันสิ้นสุด แล้วบันทึก

ริชเมนูแสดงทั้งในแชทส่วนตัวและในกลุ่มที่บอทอยู่ ไม่กินโควตาข้อความ

ฟอร์มให้เลือกวันได้ตั้งแต่ **ย้อนหลัง 7 วัน** จนถึง **สิ้นรอบถัดไป** จึงแจ้งล่วงหน้าข้ามรอบได้เลย

## โครงสร้างข้อมูล

ระบบ **แยกที่เก็บข้อมูลออกจากหน้าตาราง** เพื่อให้ใช้ต่อได้เป็นปี ๆ โดยไม่ต้องมีใครมาลบชีทรอบเก่า

### ชีท `บันทึกเวร` — แหล่งข้อมูลจริง

1 แถว = พนักงาน 1 คน 1 วัน ต่อท้ายลงล่างไปเรื่อย ๆ ไม่มีวันเต็ม (35 คน × 365 วัน ≈ 12,800 แถว/ปี ขณะที่ Google Sheets รับได้ 10 ล้านเซลล์)

| วันที่ | รหัส | ชื่อ | กะ | สถานะ | เลขคำขอ | ผู้แจ้ง | ผู้พิจารณา | เวลาอัปเดต |
|---|---|---|---|---|---|---|---|---|
| 2026-09-26 | KB028 | ทราย | 21.00-05.00 | อนุมัติ | R0001 | หัวหน้า | พี่HR | ... |

สถานะมี 4 ค่า `รออนุมัติ` `อนุมัติ` `ไม่อนุมัติ` `แทนที่` — ค่าที่ใช้จริงของคนหนึ่งในวันหนึ่งคือแถว `อนุมัติ` ที่อยู่ล่างสุด **ห้ามลบแถว** เพราะประวัติและเลขคำขอจะเสีย

### ชีท `พนักงาน` — ทะเบียนคน

`รหัส | ชื่อ - สกุล | ชื่อเล่น | แผนก | ชื่อในกลุ่มไลน์ | ค่าแรง | หน่วย | วันเริ่มงาน | วันที่ออก | หมายเหตุ`

- **คนลาออกอย่าลบแถว** ให้ใส่ `วันที่ออก` แทน ฟอร์มจะไม่แสดงคนนั้นอีก แต่ประวัติเก่ายังอ่านได้ครบ
- คนเข้าใหม่ = เพิ่มแถวลงล่าง ใส่ `วันเริ่มงาน` ได้ถ้าจะเริ่มในอนาคต
- เว้น `วันเริ่มงาน`/`วันที่ออก` ว่าง = ทำงานอยู่ตลอด
- ชื่อที่แสดงในฟอร์มใช้ชื่อเล่น ถ้าไม่มีจะใช้ชื่อจริง และ **คนที่ไม่มีรหัสจะไม่แสดงในฟอร์ม**

### ชีท `รอบ 2569-09` — ตารางแนวกว้างสำหรับดู/พิมพ์

หน้าตาเหมือนตารางเดิม (วันเป็นคอลัมน์) แต่ **สร้างจากบันทึกเวรด้วยสคริปต์** สั่งสร้างได้จากเมนู **ตารางทำงาน → สร้าง/รีเฟรชตารางรอบปัจจุบัน** ลบทิ้งเมื่อไหร่ก็ได้แล้วกดสร้างใหม่

- รอบ = วันที่ 26 เดือนก่อน ถึง 25 เดือนนี้ ชื่อชีทใช้ปี พ.ศ. กับเดือนที่รอบไปจบ
- สีมีความหมายเหมือนเดิม แต่ใช้การจัดรูปแบบตามเงื่อนไข จึงไม่หายเวลาสร้างใหม่ — ส้ม = ยังรออนุมัติ, เหลือง = หยุด/ลากิจ/ลาป่วย/ขาดงาน, หัวคอลัมน์วันอาทิตย์เป็นสีเหลือง
- ช่องที่ยังรออนุมัติจะมีโน้ตบอกเลขคำขอและผู้แจ้ง

### ชีท `คำขอ` และ `ผู้ใช้ระบบ`

- `คำขอ` เก็บประวัติทุกคำขอ: ผู้แจ้ง วันที่ รายการ สถานะ ผู้อนุมัติ เวลา และเหตุผล
- `ผู้ใช้ระบบ` มีคอลัมน์ userId, ชื่อ, บทบาท (`หัวหน้างาน` หรือ `HR`) และแผนกที่ดูแล (คั่นด้วย `,` ถ้าเว้นว่างจะเห็นทุกแผนก) แผนกที่ดูแลจะแสดงเปิดไว้ก่อนในฟอร์ม ส่วนแผนกอื่นจะพับไว้

## ค่าใช้จ่าย

ใช้ได้ฟรีทั้งหมด ได้แก่ Google Sheets + Apps Script, GitHub Pages, LINE Developers และ LINE OA แพ็กเกจฟรี

สิ่งเดียวที่ต้องระวังคือ **โควตาข้อความ push ของ LINE OA แพ็กเกจฟรี** (ประมาณ 300–500 ข้อความ/เดือน ตรวจตัวเลขล่าสุดในหน้าจัดการ LINE OA)

- reply (บอทตอบทันทีหลังมีคนพิมพ์) และข้อความที่ LIFF ส่งในนามผู้ใช้ **ไม่นับโควตา**
- push **นับโควตา** ระบบใช้ push แค่ 2 จุด คือการ์ดแจ้ง HR และแจ้งผลกลับหัวหน้าที่ส่ง ทั้งสองส่งในแชทส่วนตัว
- ถ้าแจ้งวันละครั้งต่อหัวหน้า จะใช้ประมาณ 180 ข้อความ/เดือน ยังอยู่ในโควตาฟรี
- **ห้ามให้บอท push เข้ากลุ่มใหญ่** เพราะนับตามจำนวนสมาชิกในกลุ่ม

## วิธีตั้งค่า

แนะนำให้ทดสอบกับ **สำเนาของไฟล์** และ **กลุ่มไลน์ทดลอง** ก่อน ใช้เวลาประมาณ 1–2 ชั่วโมง

### ขั้นที่ 1: Google Sheets + Apps Script

1. อัปโหลดไฟล์ xlsx เข้า Google Drive แล้วกด เปิดด้วย Google ชีต → ไฟล์ → บันทึกเป็น Google ชีต
2. ไปที่ ไฟล์ → การตั้งค่า แล้วตั้งเขตเวลาเป็น **(GMT+07:00) Bangkok** และตรวจว่ารหัส `018`, `013` ยังมีเลข 0 นำหน้า
3. ไปที่ ส่วนขยาย → Apps Script แล้ววางโค้ดจาก `Code.gs`
4. เลือกฟังก์ชัน `setup` แล้วกด Run และกดอนุญาตสิทธิ์ (ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง → ไปที่โปรเจกต์) จะได้ชีท `พนักงาน`, `บันทึกเวร`, `คำขอ`, `ผู้ใช้ระบบ`
5. กลับไปที่ชีท รีโหลดหน้า จะมีเมนู **ตารางทำงาน** โผล่ขึ้นมา กด **ย้ายข้อมูลจากชีทเดิม (ครั้งเดียว)** เพื่อดึงรายชื่อและตารางเดิมจากชีท `รหัสพนักงาน` เข้าสู่โครงสร้างใหม่ (กดซ้ำได้ ไม่เพิ่มข้อมูลซ้ำ)
6. กด **ตารางทำงาน → ตรวจการตั้งค่า** ดูผลใน Execution log ว่าอ่านพนักงานครบไหม
7. กด **ตารางทำงาน → สร้าง/รีเฟรชตารางรอบปัจจุบัน** เพื่อดูว่าตารางแนวกว้างออกมาถูกต้อง
8. กด Deploy → New deployment → Web app ตั้ง Execute as: **Me** และ Who has access: **Anyone** แล้วคัดลอก URL `/exec` เก็บไว้

ชีท `รหัสพนักงาน` เดิมและแท็บรายคน (`1`, `2`, `KB036`, …) เก็บไว้ได้ ระบบไม่แตะต้องอีกแล้ว

### ขั้นที่ 2: บอท LINE (Messaging API)

1. เข้า manager.line.biz แล้วสร้าง LINE Official Account
2. ไปที่ ตั้งค่า → Messaging API → เปิดใช้งาน และสร้าง Provider (เช่น "KB")
3. ไปที่ ตั้งค่าการตอบกลับ: ปิดข้อความตอบกลับอัตโนมัติและข้อความทักทาย แล้วเปิด **Webhook**
4. ไปที่ ตั้งค่าบัญชี: เปิด "อนุญาตให้เข้าร่วมแชทกลุ่ม"
5. เข้า developers.line.biz → ช่อง Messaging API → แท็บ Messaging API
   - Webhook URL: ใส่ URL `/exec` และเปิด Use webhook (ถ้า Verify ขึ้น error 302 ไม่เป็นไร)
   - Channel access token (long-lived): กด Issue แล้วคัดลอกเก็บไว้

### ขั้นที่ 3: หน้าฟอร์ม LIFF

1. สร้างช่อง **LINE Login ใน Provider เดียวกัน** (สำคัญ เพราะ userId ผูกกับ Provider) แล้วคัดลอก Channel ID
2. แท็บ LIFF → Add: Size เลือก **Full**, Scopes เลือก **openid, profile, chat_message.write**, Endpoint ใส่ `https://example.com` ไปก่อน แล้วคัดลอก LIFF ID
3. แก้ `CONFIG` ด้านบนของ `index.html` ให้ใส่ `LIFF_ID` และ `GAS_URL`
4. ที่ GitHub สร้าง repository แบบ Public → อัปโหลด `index.html` → ไปที่ Settings → Pages → เลือก branch `main` แล้วกด Save จะได้ URL `https://<user>.github.io/<repo>/`
5. กลับไปแก้ Endpoint URL ของ LIFF เป็น URL ของ GitHub Pages

### ขั้นที่ 4: ใส่รหัสลับ และลงทะเบียนผู้ใช้

1. ใน Apps Script ไปที่ Project Settings → Script properties แล้วเพิ่ม 3 ค่า:
   - `CHANNEL_ACCESS_TOKEN`
   - `LOGIN_CHANNEL_ID`
   - `LIFF_ID`
2. เพิ่มบอทเป็นเพื่อน แล้วพิมพ์ `myid` บอทจะตอบ userId กลับมา
3. ใส่ userId ในชีท `ผู้ใช้ระบบ` ช่วงทดสอบให้ตั้งตัวเองเป็น `HR` เพราะ HR ส่งคำขอได้ด้วย

### ขั้นที่ 5: ทดสอบ

เชิญบอทเข้ากลุ่มทดลอง แล้วทำตามลำดับ

1. พิมพ์ `แจ้งงาน` → แจ้งวันทำงาน → เลือกคนและเวลา → ส่งขออนุมัติ
2. เช็กว่าชีท `บันทึกเวร` มีแถวสถานะ `รออนุมัติ` และมีการ์ดแจ้ง HR ในแชทส่วนตัว
3. กดตรวจและอนุมัติ แล้วเช็กว่าสถานะเปลี่ยนเป็น `อนุมัติ`
4. ทดสอบกรณีไม่อนุมัติด้วย สถานะต้องเป็น `ไม่อนุมัติ` และไม่มีแถว `อนุมัติ` ของวันนั้น
5. กดเมนู **ตารางทำงาน → สร้าง/รีเฟรชตารางรอบปัจจุบัน** แล้วดูว่าตารางตรงกับที่แจ้งไป

| ปิดรอบ ส่งบัญชี | กด **สร้าง/รีเฟรชตารางรอบก่อนหน้า** แล้วพิมพ์หรือส่งชีทนั้น |
| พนักงานเข้าใหม่ | เพิ่มแถวในชีท `พนักงาน` ใส่รหัส ชื่อ ชื่อเล่น แผนก |

| ชีทรอบเก่ารก | ลบแท็บทิ้งได้เลย ข้อมูลจริงอยู่ที่ `บันทึกเวร` |

## ก่อนใช้งานจริง

- ช่อง LINE Login ต้องกด **Publish** (ออกจากสถานะ Developing) หัวหน้าคนอื่นถึงจะเปิดฟอร์มได้
- เติมรหัสพนักงานที่ยังว่าง (น้ำค้าง, ลักขณา, อุ๋มอิม, ธนวัฒน์) และชื่อเล่นที่ยังว่าง (เช่น KB070, KB081, KB078–KB080, KB001, KB003) ในชีท `พนักงาน`
- ชื่อเล่นต้องไม่ซ้ำกัน `ตรวจการตั้งค่า` จะเตือนถ้าซ้ำ
- ให้หัวหน้า 3 คนและหัวหน้า HR พิมพ์ `myid` แล้วนำ userId มาใส่ในชีท `ผู้ใช้ระบบ`
- ถ้าแก้ `Code.gs` ต้องกด Deploy → Manage deployments → แก้ไข → **New version** ทุกครั้ง (URL เดิมยังใช้ได้)

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่เป็นไปได้ |
|---|---|
| พิมพ์ `myid` แล้วบอทเงียบ | Webhook URL ผิดหรือยังไม่เปิด Use webhook, ยังไม่ได้ใส่ `CHANNEL_ACCESS_TOKEN` หรือยังไม่ได้ปิดตอบกลับอัตโนมัติ |
| ฟอร์มขึ้น "ยืนยันตัวตนไม่สำเร็จ" | `LOGIN_CHANNEL_ID` ผิด, ไม่ได้เลือก scope `openid` หรือเปิดฟอร์มค้างไว้นานเกินไป (ให้ปิดแล้วเปิดใหม่) |
| ฟอร์มขึ้น "บัญชีนี้ยังไม่มีสิทธิ์ใช้งาน" | ยังไม่ได้ใส่ userId ในชีท `ผู้ใช้ระบบ` |
| ฟอร์มไม่มีชื่อพนักงานบางคน | ยังไม่มีรหัสในชีท `พนักงาน` หรือมี `วันที่ออก` ไปแล้ว |
| วันที่เลื่อนไป 1 วัน | เขตเวลาของชีทไม่ใช่ Bangkok |
| ข้อความสรุปไม่ขึ้นในกลุ่ม | ไม่ได้เลือก scope `chat_message.write` หรือเปิดฟอร์มจากนอกแชท |
| ไม่มีเมนู "ตารางทำงาน" ในชีท | รีโหลดหน้าชีทหลังวางโค้ด ถ้ายังไม่ขึ้นให้ Run ฟังก์ชัน `onOpen` หนึ่งครั้ง |
| ตารางรอบไม่ตรงกับที่แจ้ง | กดสร้าง/รีเฟรชใหม่ ชีทรอบไม่ได้อัปเดตอัตโนมัติ |
| แก้โค้ดแล้วไม่มีผล | ยังไม่ได้ Deploy เป็น New version |
| เชิญบอทเข้ากลุ่มแล้วบอทออกเอง ("BOT ... left the group") | ยังไม่ได้เปิด "อนุญาตให้เข้าร่วมแชทกลุ่มและห้องแชท" ใน manager.line.biz → ตั้งค่า → ตั้งค่าบัญชี (และโหมดตอบกลับต้องเป็นแชทบอท) |
| เรียกชื่อบอทแล้วเงียบ | โหมดตอบกลับยังเป็น "แชท" หรือยังไม่ได้ Deploy โค้ดใหม่ |
